Study Tracker is a self-contained daily/weekly study-habit tracker that helps you hit a weekly goal of 5 hours per subject (20h total for 4 subjects). It's a single HTML page (no server needed) with a dark, fully customizable theme.

Daily & weekly progress

Today view shows exactly what you studied today per subject, plus a progress bar toward each subject's weekly 5-hour goal and a ✅ when it's reached.
Overall percentage follows a capped weekly model: you only reach 100% by hitting 5h in every subject — studying extra in one doesn't inflate the total.
Weekly view shows Monday→Sunday history with the real hours studied each day, per-subject weekly totals, and whether each goal was met. Old weeks are kept automatically and reset each Monday.
Timers

Per-subject stopwatch with start/stop and manual time entry; multiple sessions accumulate.
A big fullscreen timer overlay with customizable text and background colors (default white-on-black).
A Pomodoro timer tied to each subject, with customizable work/short/long break durations. Completed pomodoros add their minutes to that subject's time; skipping only counts the time actually elapsed.
Reminders

Optional daily reminders at a chosen time that skip any subject already at its goal.
Email reminders sent through EmailJS (connected to Gmail) listing which subjects still need work.
Customization

Add, remove, or rename subjects freely.
Choose a theme color (blue, red, black, green, etc. or any custom color) — the whole site's background, cards, progress bars, and text recolor automatically with readable contrast.
Data

Everything auto-saves to your browser's storage (per-PC), and Export/Import JSON buttons let you back up or move data between devices — so on GitHub Pages every user keeps their own data on their own machine.
